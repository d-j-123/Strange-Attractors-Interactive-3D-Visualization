#Strange Attractors — Interactive 3D Visualization

An interactive Python application for exploring chaotic dynamical systems through numerical simulation and 3D visualization. The project implements the fourth-order Runge–Kutta (RK4) method to solve systems of ordinary differential equations and uses PyVista to visualize their trajectories in 3D.

User can interactively modify system parameters and initial conditions using sliders and observe how these changes affect the resulting dynamics.

##Features

- Multiple chaotic systems: Lorenz, Rössler, Thomas, Aizawa, Halvorsen, and Chen attractors.
- Custom implementation of the fourth-order Runge–Kutta method
- Interactive visualization: Explore trajectories in a 3D environment using PyVista.
- Real-time parameter adjustment: Modify system parameters and initial conditions through interactive sliders.

##Technologies

- Python
- Numpy
- PyVista
